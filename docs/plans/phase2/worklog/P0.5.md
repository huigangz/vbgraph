## Notes

The plan's pseudocode signature is `persistScipIndex(scipPath, metadata, ctx)`. The
implemented persister takes a single `ScipPersistOptions` object and re-opens its own
streams as needed, so `ingestScipFile` does not thread `metadata` through — it reads it
purely as the fail-fast guard. The `metadata` value is retained at the call site
(`void metadata`) as the hook for the future indexer version-mismatch warning (P0.4c's
`version-mismatch` mode), which is surfaced by the P0.6 orchestrator.
