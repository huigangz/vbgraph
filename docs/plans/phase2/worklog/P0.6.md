# P0.6 — Orchestrator dual-backend dispatch — Work Log

**Status:** Done.
**Date:** 2026-05-20

## Scope delivered

`codegraph index` now drives both backends: SCIP for covered files, tree-sitter for the
rest.

### `src/index.ts` — `CodeGraph`

- `IndexOptions` gains `scip?: string[]`, `scipAuto?: boolean`, `noScip?: boolean`,
  `languages?: string[]`.
- New private `runScipPrePass(options)`:
  1. Resolves SCIP sources — explicit `--scip` paths ∪ `config.scipSources.files`, plus
     `--scip-auto` spawn output.
  2. `--scip-auto`: scans the repo for present languages, runs `runScipAutoSpawn`.
  3. Ingests each `.scip` via `ingestScipFile`. **Explicit** paths are caller-asserted-valid
     — a corrupt file or `MultiIndexConflictError` is fatal (propagates). **Auto-spawned**
     paths degrade to tree-sitter on failure and are recorded in the failure ledger.
  4. Returns the `scip_documents` covered-file set.
- `indexAll` runs the pre-pass first; on a fatal SCIP error it returns
  `{ success: false, errors: [...] }` (the persister's STAGE A ran before any mutation, so
  the DB is unchanged — ship gate 12a). It then passes the covered set to the orchestrator.

### `src/extraction/index.ts` — `ExtractionOrchestrator`

- `indexAll` gains an `excludePaths?: ReadonlySet<string>` parameter; the scanned file list
  is filtered against it **after** framework detection (detection still sees the full
  scan), so SCIP-covered files are never re-extracted by tree-sitter.

### `src/extraction/scip/auto-spawn.ts` (new) — `runScipAutoSpawn`

- Acquires the `.scip-auto.lock`, detects indexers (or accepts injected `detected` for
  tests), spawns each — **sequentially, lightest toolchain first** — for the languages
  present in the repo (∩ `--languages` filter, ∉ `disabledScipIndexers`).
- Each indexer's stdout/stderr is captured to `.codegraph/logs/<name>-<ts>.log`; output
  goes to `.codegraph/scip-cache/<name>.scip`.
- Per-indexer failure isolation: a failed indexer yields a `ScipFailure` (classified via
  `classifyScipFailureMode`) and the run continues — never aborts.

### `src/extraction/scip/detect-indexers.ts`

- `ScipIndexerSpec.indexArgs?` + `defaultScipIndexArgs` (`index --output <path>`).

### Test — `__tests__/p06-dual-backend.test.ts` (6 tests)

`--scip` ingests SCIP + tree-sitters the rest (verified per-file provenance, and the
SCIP file is **not** tree-sitter re-extracted); `--no-scip` forces Tier 0; a corrupt
explicit `--scip` fails the index with `success:false` and zero nodes; `runScipAutoSpawn`
spawns a fake indexer and returns the `.scip`, records a failure on non-zero exit, and
skips an indexer whose languages are absent.

## Notes / deviations

- **Auto-spawn CLI convention is best-effort.** No SCIP indexer is installed in this
  environment, so the per-indexer `index --output <path>` invocation is unverified against
  real indexers. `ScipIndexerSpec.indexArgs` is the per-indexer override point; confirming
  exact CLIs is a follow-up. The spawn *loop* is fully tested with fake indexers.
- **P0.6 step 6 (scope-resolved pass)** is P0.5b's deliverable — not yet wired; the
  pipeline runs without it until P0.5b lands.
- SCIP edges already carry `provenance='scip'` and are persisted resolved, so they bypass
  the heuristic resolution stage automatically (plan step 7) — no extra wiring needed.
