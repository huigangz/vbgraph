## Risk callouts

- **Partial-index cost in `INSERT`s that write `stale=0`**: zero — SQLite skips partial indexes when the row doesn't match the WHERE clause. The dominant write path (insertNode, insertScipNode, upsertGraphEdge writing `stale=0`) pays no index-maintenance cost.
- **Partial-index size on hidden-stale rows**: bounded by `maxStaleFilesPerSync × nodes-per-file × 2 columns indexed = O(N hidden)`. For 50 hidden files × ~50 nodes each = 2500 entries; well under any concern threshold.
- **Migration ordering**: v7 runs AFTER v5 (which created the `stale` column) and v6 (node_tags). No cross-dependency — partial-index DDL only touches columns that have existed since v5.
