## Risk callouts (consolidated)

- **No `package.json` bump at P1's 0.8.0 release** — CHANGELOG had the 0.8.0 entry but `package.json` stayed at 0.7.12. P2.6.3 jumps directly to 0.9.0. User can fold 0.8.0 into 0.9.0 release or publish both — out of scope.
- **CHANGELOG `[0.8.0]` link reference missing** — same root cause as above. User-driven publish call.
- **Perf test threshold is 1500ms on WASM** (vs 200ms native). If a CI worker is unusually slow, may flake — bump to 3000ms before assuming a real regression.
- **Cross-platform scheduler templates not auto-tested** — execution requires real scheduler daemons + indexer binaries. Manual install per OS.
