# P0.8 — Types, config, EXTENSION_MAP, Node touch points — Work Log

**Status:** Done.
**Date:** 2026-05-20

## Scope delivered

### `src/types.ts`

- New `GraphProvenance` union: `tree-sitter | tree-sitter (scip-empty-fallback) |
  scope-resolved | scip | scip:external | heuristic | framework:${string}`.
- `Node` gains optional `provenance` / `scipSymbol` / `scipIndexPath` (optional so the many
  existing `const node: Node = {...}` literals keep compiling).
- `Edge.provenance` widened from the 3-value union to `GraphProvenance`; `Edge` also gains
  optional `provenances: GraphProvenance[]`, `confidence: number`, `subkind: string`.
  `EdgeKind` is intentionally **not** extended — subkinds ride the free-form `subkind`
  column (architecture decision 3).
- `CodeGraphConfig` gains `scipSources` (`{ files?, glob? }`), `emptyFallbackThresholdBytes`
  (default 200), `scipAuto`, `disabledScipIndexers` — all optional.
- `DEFAULT_CONFIG.include` gains `'**/*.vb'`.

### `src/extraction/grammars.ts`

- `EXTENSION_MAP['.vb'] = 'vbnet'`.

### `src/config.ts`

- `validateConfig`'s hand-maintained `validLanguages` list (only 8 of the languages —
  stale, missing csharp/ruby/etc.) replaced by a check against the canonical `LANGUAGES`
  array. Bug fixed in passing: configs naming e.g. `csharp` were previously rejected.

### `src/db/queries.ts` — Node QueryBuilder touch points

- `NodeRow` gains `provenance` / `scip_symbol` / `scip_index_path`.
- `rowToNode` maps the three columns back onto `Node`.
- `insertNode`'s `INSERT OR REPLACE` lists the three columns and binds them
  (`provenance` defaults to `'tree-sitter'`, the SCIP fields default to `NULL`).
- `updateNode` **deliberately left untouched** — a doc comment now declares that
  `provenance` / `scip_*` are insert-time-only; SCIP re-ingestion replaces ownership via
  the persister's scoped delete + re-insert, never via `updateNode`.
- Grep confirmed no other direct `INSERT INTO nodes` / `UPDATE nodes` sites
  (the `nodes_fts` trigger inserts are unrelated).

### Test — `__tests__/p08-node-provenance-roundtrip.test.ts` (3 tests)

Node inserted with all three fields round-trips through `getNodeById`; a plain node
defaults `provenance` to `'tree-sitter'` with the SCIP fields unset; a `framework:aspnet`
provenance value is accepted.

## Interim-state note

`.vb` is now in `EXTENSION_MAP` and `DEFAULT_CONFIG.include`, but `vbnet` has no extractor
until **P0.6b** (the WASM grammar + `languages/vbnet.ts`). Until then `vbnet` is not in
`SELF_HOSTED_WASM_LANGUAGES`, so a grammar-load attempt fails and `.vb` files are skipped
gracefully — the expected pre-P0.6b behavior, and consistent with the user's earlier
question about `.vb`/`EXTENSION_MAP`.
