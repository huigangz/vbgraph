## Deviations from the plan (and why)

1. **Pass 1 inserts internal nodes**, not just the symbol map. `edges.target` has an FK to
   `nodes` and the DB runs `foreign_keys=ON`, so every internal edge target must exist
   before STAGE E inserts edges. Pass 1 = symbol map + all internal nodes; Pass 2 = edges.
2. **STAGE A duplicate detection uses an in-process `Set`**, not a `scip_docs_seen` TEMP
   table — the WASM SQLite backend reports "table is locked" when DROP-ing a TEMP table
   that prepared statements still reference, and STAGE A must leave zero residue.
3. **The symbol-map TEMP tables are emptied (`DELETE FROM`), never `DROP`-ed** — same WASM
   lock reason. Memory-equivalent: cleared after each ingest, gone on connection close.
4. **`upsertGraphEdge` normalizes via `coerceEdgePosition` rather than strict-validating**
   every edge — a strict throw would abort an entire index over one stray legacy position.
   Strict `validateEdgeLineColumn` is still exported and applied by the persister to the
   SCIP edges it builds, and by tests.
5. **`insertScipNode` is `INSERT OR IGNORE`** (plan said `OR FAIL`) — consistent with
   STAGE D's tolerance of duplicate definitions, and `OR REPLACE` would cascade-delete
   edges via the FK.
6. **Unresolved SCIP references are counted (`stats.unresolvedCount`), not written to
   `unresolved_refs`** — that table feeds the tree-sitter heuristic resolver; a SCIP miss
   is an indexer quirk, not a resolvable reference.

## Follow-up — containment derivation (surfaced by P0.10)

Validating against a *real* `scip-dotnet` index (P0.10) exposed that containment
and call-site enclosure here relied on definition occurrences carrying
body-spanning ranges. The synthetic fixtures provide that; `scip-dotnet` 0.2.14
does not (name-token-only ranges, empty `enclosing_range`), so the real graph
came out flat — file-contains-everything, every call edge sourced from the file
node.

Fixed in `persister.ts`: containment is now derived from the SCIP **symbol
descriptor path** (`A#foo().` is contained by `A#`), which is range-independent;
positional `enclosingDefinition` is retained as the fallback for indexers that
do emit body-spanning ranges, so all 13 synthetic tests stay green. Call-site
enclosure gained a nearest-preceding-scope fallback, and a method
`isImplementation` relationship now emits `overrides` rather than a malformed
`extends` between two `method` nodes. See `worklog/P0.10.md`.
