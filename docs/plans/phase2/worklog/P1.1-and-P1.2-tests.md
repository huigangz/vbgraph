## Helpers / discovered issues

- The local `objectExists` helper was made WASM-resilient
  (`row !== undefined && row !== null`). The same helper in p09 uses
  better-sqlite3 semantics; both tests run green on the WASM backend
  because the WASM `.get()` returns `null` rather than `undefined`.
  Not a code path under test — just a test-helper compatibility fix.
- Idempotent-migration check uses `getCurrentVersion(db)`, not the
  hardcoded `fromVersion` passed to the previous `runMigrations` call.
  `runMigrations(db, 5)` would re-apply the v6 migration because the
  filter is `m.version > fromVersion`, not `> currentDbVersion`. Real
  callers pass the DB-derived version, so the test now mirrors that.
