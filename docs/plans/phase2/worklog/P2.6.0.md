## Decisions

**Single test file for P2.6.2** (not 6 files): the semantic regressions all probe the same QueryBuilder/CodeGraph surface, share the same setup pattern, and reading them together makes the "what could break the staleness model" surface obvious. ~250 lines total.

**Perf regression as standalone file**: timing assertions are flaky in shared test runs (worker contention). Isolating lets us bump the threshold or skip in CI without disrupting semantic tests.

**No `*IncludingDanglingEndpoints` siblings yet exist** — they were deferred in P2.1.6 worklog. Endpoint-visibility test will assert the DEFAULT filters (works without siblings); add a sibling-comparison case once a sibling lands. Not a P2 blocker.
