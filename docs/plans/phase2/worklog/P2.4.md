## Status command — new sections

**Text mode**:

```
Staleness:                                          (omitted when fresh)
  Shadow active:  3 file(s) — 47 nodes hidden behind tree-sitter shadow
  Needs refresh:  1 file(s) — 12 nodes shown stale (no tree-sitter grammar)
  Raw totals:     12,580 nodes / 28,123 edges (filtered: 12,521/28,049)

SCIP:                                               (always shown when initialized)
  Last refresh:  2h ago — 1,234 file(s) in 5.6s    (or "never")
  csharp       Tier 1 SCIP (scip-dotnet)
  vbnet        Tier 0 tree-sitter — upgrade: dotnet tool install -g scip-dotnet
  typescript   Tier 0 tree-sitter
ℹ Run "codegraph scip-refresh" to restore SCIP precision   (only when needsRefresh)
```

**JSON mode** — adds 5 fields: `stale`, `rawTotals`, `lastScipRefresh`, `languageTiers`, `needsRefresh`. Existing fields unchanged.

## Observable behavior changes

1. **`codegraph status` now reports SCIP coverage tier per language** even on a fresh DB — helps users discover Tier 0 vs Tier 1 distinctions without running `--scip-auto`.
2. **Staleness section appears only when relevant** — fresh DBs see no noise.
3. **Refresh hint surfaces automatically** when any file is stale (visible OR hidden).
4. **JSON output is additive** — 5 new fields, no removals. Existing programmatic consumers unaffected.
5. **`getStats()` already changed in P2.1.7** (excludes hidden-stale); `getStatsIncludingStale()` now public for callers needing raw counts. Both surfaces propagated through to CLI.

## Risk callouts (consolidated)

- **SCIP indexer detection adds ~5s on cold processes** with most indexers absent. Cached after first call. Status command suite uses `beforeAll` warmup; production CLI sees one-time cost per `status` invocation.
- **Status JSON shape change is additive** — backward compatible. CHANGELOG (P2.6) flags as a non-breaking enhancement.
- **No MCP exposure of the new fields** — `codegraph_status` MCP tool still returns the pre-P2.4 shape. Extension is P3 follow-up.
- **`getLanguageTiers()` is async** — first method on CodeGraph in this category. CLI awaits it; no API consumers other than CLI today.
- **Sidecar reader treats absent / corrupt / partial as null** — status uniformly renders "never refreshed". Acceptable; users wanting the distinction can `cat` the file.
