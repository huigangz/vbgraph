# P0.2 — Protobuf tooling (runtime only) — Work Log

**Status:** Done.
**Date:** 2026-05-20

## Ordering note

P0.2 was executed **before P0.1**. P0.1's streaming decoder calls
`Document.decode(bytes)` / `SymbolInformation.decode(bytes)`, which are the protobufjs
message types this sub-phase provides — P0.2 is a hard dependency of P0.1. Work logs are
still one-per-sub-phase as requested; only the execution order was dependency-driven.

## Scope delivered

Per the plan's decision: **no code generation**. `protobufjs` runtime reflection only — no
`protobufjs-cli` devDependency, no generated `.js`/`.d.ts` artifacts to keep in sync.

### Dependency added

- `protobufjs@^7` (resolved 7.6.0), runtime dependency. Ships its own `.d.ts`, so no
  `@types/*` package is needed.

### Vendored schema

- `src/extraction/scip/scip.proto` — copied verbatim from
  `github.com/sourcegraph/scip/blob/main/scip.proto`, pinned at commit
  **`212ec4bea21c8b4a9c1f796fa0f79c607b4e6e35`** (recorded in the file's header comment).
  Written UTF-8 **without BOM** (via .NET `UTF8Encoding($false)`) so protobufjs's parser
  does not choke on a leading BOM. 33,339 bytes including the 7-line vendor header.
  - Confirmed top-level field numbers for the P0.1 wire decoder:
    `Index.metadata = 1`, `Index.documents = 2` (repeated), `Index.external_symbols = 3`
    (repeated) — all wire-type 2 (length-delimited). `package scip;`.

### New file

- `src/extraction/scip/proto-loader.ts`
  - `loadScipProtoTypes()` — `protobuf.load()` the vendored `.proto`, then `lookupType`
    for `scip.Index / Metadata / Document / SymbolInformation / Occurrence`. The result
    promise is cached per process; a rejected load clears the cache so it can be retried.
  - `scipProtoPath()` — resolves `scip.proto` via `__dirname`, which works in both `src/`
    (tests / tsx) and `dist/` (shipped) because of the `copy-assets` change below.
  - `clearScipProtoTypeCache()` — test seam.

### Build wiring

- `package.json` `copy-assets` script extended to `mkdir dist/extraction/scip` and copy
  `scip.proto` into it. Without this the shipped package would fail at runtime — the
  plan's standing rule that any new asset must be copied or it won't ship.

## Verification

- `npx tsc --noEmit` — clean.
- `protobuf.load('src/extraction/scip/scip.proto')` resolves and `lookupType` succeeds for
  all 5 message types (verified via a node one-liner and via `loadScipProtoTypes()` over
  tsx).

A dedicated `p02` test file is intentionally not added — the plan lists no such file, and
the loader is exercised end-to-end by the P0.1 streaming-decoder tests.
