## Design choices

- **Defaulted to 03:00 daily** — quiet hours on most workstations; documented as adjustable in each template's header.
- **Quiet flag (`--quiet`)** — all three templates use `codegraph scip-refresh --quiet`. Schedulers capture stderr for failures; stdout chatter on every cron tick is noise.
- **systemd: user-mode default** — avoids `sudo` requirement. Header documents the system-mode alternative with `User=` directive.
- **systemd: resource caps** — `MemoryMax=4G`, `CPUQuota=50%`, `Nice=10`, `IOSchedulingClass=idle`. scip-dotnet can spike to 2-4 GB on large solutions; the caps prevent starving interactive work.
- **systemd: timer jitter `±10min`** — avoids thundering-herd on shared infrastructure where many machines might be scheduled at the same time.
- **Task Scheduler: `DisallowStartIfOnBatteries=true`** — laptop-friendly. Set to `false` if you want laptop refreshes regardless of power state.
- **Task Scheduler: UTF-8 encoding** — template ships as UTF-8 with a matching `<?xml version="1.0" encoding="UTF-8"?>` declaration. Recent `schtasks` builds accept UTF-8 directly; the template header documents the PowerShell conversion (`Set-Content -Encoding Unicode`) for older Windows versions that require UTF-16. (Note: the original P2.5 audit on 2026-05-24 described UTF-16 here; the encoding declaration was corrected in the 2026-05-25 review round 1 to match the actual file bytes — see [P2-review-round-1.md](P2-review-round-1.md) finding #5.)

## Placeholders (per template)

Every template uses obvious uppercase placeholders so a quick grep finds them all:

- `REPLACE_WITH_NODE_BIN` (launchd only — Task Scheduler runs codegraph.cmd directly; systemd uses the script's own shebang)
- `REPLACE_WITH_CODEGRAPH` (path to the `codegraph` binary / `.cmd` shim)
- `REPLACE_WITH_PROJECT` (absolute path to project root)
- `REPLACE_WITH_USER` (Task Scheduler only — `domain\username` form)

Header in each template lists `which` / `where` commands to resolve them.

## Exit-code surfacing per scheduler

| Scheduler | How non-zero surfaces |
|---|---|
| launchd | `launchctl list \| grep com.codegraph` shows last exit; stderr captured to `StandardErrorPath` |
| systemd | `systemctl --user status codegraph-scip-refresh` → "failed"; `journalctl --user -u codegraph-scip-refresh -e` for stderr |
| Task Scheduler | History pane; "Last Run Result" column in the task list |

## What's NOT in this sub-task

- **Cross-platform `codegraph schedule install` helper** — deferred to P3 per the design.
- **CI integration** (GitHub Actions / GitLab CI variants for shared `.scip` artifacts) — separate concern; the design's "Out of scope" section calls it out.
- **Email / Slack notification on failure** — out of scope; pipe exit codes via the user's existing alerting.
- **Schedule install / uninstall scripts** (sh / ps1) — deferred. Templates + README are enough for a P2 ship; helpers can come later.
