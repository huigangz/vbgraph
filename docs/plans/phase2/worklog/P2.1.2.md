# P2.1.2 — `freshPredicate` + `visibleNodeIdPredicate` helpers

**Status**: complete
**Date**: 2026-05-24
**Decisions**: Design doc Decisions 4 and 7 (and round 3 finding 2 — predicate-only API form).

## Changes

### `src/db/queries.ts`

Added two module-level exports right before the `QueryBuilder` class. Both are pure-string returns; no SQL execution, no side effects.

```ts
export function freshPredicate(alias: string = ''): string;
export function visibleNodeIdPredicate(): string;
```

#### `freshPredicate(alias?)`

- Returns: `(stale = 0 OR staleness_visible = 1)` (or aliased variant `(n.stale = 0 OR n.staleness_visible = 1)`).
- Composes with explicit `WHERE` / `AND` at the call site (the round 3 fix — earlier `withFreshnessFilter(sql)` shape broke clauseless statements like `SELECT * FROM nodes`).
- `alias` parameter accepts plain `'n'` or pre-suffixed `'n.'`; both work.

#### `visibleNodeIdPredicate()`

- Returns: `NOT IN (SELECT id FROM nodes WHERE stale = 1 AND staleness_visible = 0)`.
- Designed to be `AND`-ed against an edge column (source or target).
- Uses the partial `idx_nodes_stale WHERE stale = 1` index (added in P2.1.1) for fast hidden-set lookup.

## Why the helpers are at module scope, not class methods

- The CI bypass guard test (P2.1.8) greps for calls to these names; module-level exports are easier to find and reason about than `this.freshPredicate(...)`.
- No instance state involved — pure SQL templating.
- Avoids polluting `QueryBuilder`'s autocomplete with template helpers.

## Validation

Type-checks deferred to P2.1.9's `npm run build`. Standalone unit coverage lands in P2.1.8 (CI guard) and P2.6 (semantic regressions). No callers wired yet — that's P2.1.5/6/7.

## Risk callouts

- **`alias` parameter is a stringly-typed shotgun**: callers passing `'n;'` or `'); DROP TABLE …;` could inject SQL. The constraint here is that `alias` is only ever passed as a SQL identifier literal in our own code; user input never reaches it. Worth a JSDoc note (not done — would be premature defense). If we ever wire user input to it, sanitize at that call site.
- **Subquery cost on large hidden sets**: documented in design doc "What this gives up" — N=5000 hidden threshold / 200ms test deferred to P2.6.
