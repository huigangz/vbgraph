## Scope delivered

### `src/bin/codegraph.ts` — `index` command

Four SCIP flags wired onto `codegraph index`:

- `--scip <path>` — ingest a pre-built `.scip` index. **Repeatable** (commander collector
  accumulates into a `string[]`).
- `--scip-auto` — detect installed SCIP indexers, spawn them, ingest the output.
- `--no-scip` — force Tier 0 (tree-sitter only). commander stores `--scip`/`--no-scip`
  under the same `scip` key; the action reads `options.scip === false` as the disable
  signal and `Array.isArray(options.scip)` as the path list.
- `--languages <list>` — comma-separated language subset for `--scip-auto`.

The action builds an `IndexOptions` slice (`scip` / `scipAuto` / `noScip` / `languages`)
and spreads it into all three `cg.indexAll(...)` call sites (quiet, verbose, normal).
